# TaskflowApp 🚀
A cross-platform task management system working seamlessly on both Web and Mobile environments using a shared unified database.

## 📌 Features
- **Cross-Platform:** Native mobile experience built with Flutter and a robust backend/web architecture built with TypeScript.
- **Unified Database:** Both web and mobile clients communicate with the same database, ensuring real-time data consistency.
- **Task Management:** Create, track, and manage daily workflows efficiently.

## 💻 Tech Stack
- **Mobile Client:** Flutter (Dart)
- **Backend/Web:** TypeScript 
- **Database:** PostgreSQL
